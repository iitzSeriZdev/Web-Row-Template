3X-UI تنها پنل پشتیبانی‌شده است. همهٔ دستورالعمل‌های این سایت برای 3X-UI است.

### چرا پنل‌های دیگر فقط در مرحلهٔ پژوهش‌اند

این سه پنل موتور قالب متفاوتی دارند — Go `html/template` برای 3X-UI، Jinja2 برای PasarGuard و pongo2 برای Rebecca — و صفحه‌ای که برای یکی نوشته شده در دیگری معتبر نیست. لایهٔ ظاهری CSS ساده است و منتقل می‌شود؛ اما پوستهٔ صفحه نه. پوستهٔ هر طرح برای PasarGuard و Rebecca از قبل ساخته شده و برای مطالعه در پوشهٔ `shells/` نسخه قرار گرفته است، اما نصب‌کننده هرگز آن را نصب نمی‌کند.

پرسش باز دیگر، وضعیت زنده است: 3X-UI آن را در `?format=info` ارائه می‌کند، در حالی که دو پنل دیگر از پسوند مسیر استفاده می‌کنند که به تغییر در اجرای صفحه یا یک reverse proxy نیاز دارد. این تصمیم به تعویق افتاده است.

## سرور

| | |
|---|---|
| **سیستم‌عامل** | لینوکس. پیشنهادی: Ubuntu 24.04 LTS (x86_64). |
| **پوسته و ابزارها** | `bash`، coreutils، `tar`، `sha256sum` یا `shasum`، `curl`، `awk`، `sed`، `od`، `base64` |
| **اختیاری** | `sqlite3` (فعال‌سازی خودکار و بررسی‌های بیشتر)، `systemd` (ری‌استارت سرویس هنگام فعال‌سازی) |
| **محیط اجرا** | هیچ — نه Node.js، نه Python، نه پایگاه‌داده |
