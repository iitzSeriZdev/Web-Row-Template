title: متغیرهای محیطی
description: همهٔ متغیرهایی که نصب‌کننده و فرمان row-template می‌خوانند — برای نصب بدون پرسش، منابع آفلاین و خودکارسازی.
---

Row-Template برای خود نصب‌کننده فایل پیکربندی ندارد. هر پاسخی که در سؤال‌ها می‌دهید، یا هر انتخابی دربارهٔ منبع نسخه، را می‌توان به‌صورت متغیر محیطی در خط فرمان داد. متغیر فقط برای همان فرمانی اعمال می‌شود که پیش از آن آمده؛ بین اجراها چیزی به خاطر سپرده نمی‌شود.

```bash
RT_ASSUME_NONINTERACTIVE=1 RT_TEMPLATE=prism bash install.sh
```

## انتخاب‌ها و برندینگ

| متغیر | خوانده‌شده توسط | اثر |
|---|---|---|
| `RT_TEMPLATE` | نصب‌کننده | طرحی که نصب می‌شود، با شناسه (مثلاً `editorial`). دقیق بررسی می‌شود: شناسه‌ای که این نسخه ندارد نصب را متوقف می‌کند. وقتی استفاده می‌شود که انتخابگر تعاملی طرح وجود ندارد — نصب بدون پرسش یا تعمیر. |
| `RT_SERVICE_NAME` | نصب‌کننده، `config` | نام سرویس. حداکثر ۱۲۰ نویسه، بدون نویسهٔ کنترلی. برای پاک کردن نام، آن را خالی بگذارید. |
| `RT_SUPPORT_URL` | نصب‌کننده، `config` | لینک پشتیبانی: `https://`، `http://`، `tg://` یا `mailto:`. مقدار خالی آن را پاک می‌کند. |
| `RT_LOGO_PATH` | نصب‌کننده، `config` | مسیر لوگوی PNG، JPEG یا WebP، حداکثر ۲۵۶ کیلوبایت، که از روی محتوایش شناسایی می‌شود. symlink پذیرفته نمی‌شود. |
| `RT_LOGO_REMOVE` | نصب‌کننده، `config` | هر مقدار غیرخالی، لوگو را حذف می‌کند. بر `RT_LOGO_PATH` مقدم است. |

وقتی یکی از این‌ها تنظیم شده باشد، سؤال مربوط پرسیده نمی‌شود. نصب‌کننده متغیرهای برندینگ را فقط در **اولین** نصب می‌خواند؛ تعمیر، پیکربندی موجود را نگه می‌دارد. برای تغییر برندینگ در ادامه، از آن‌ها با `row-template config` استفاده کنید:

```bash
RT_ASSUME_NONINTERACTIVE=1 RT_SERVICE_NAME="Aurora VPN" row-template config
```

مقادیری که تنظیم نکنید مقدار فعلی‌شان را حفظ می‌کنند.

## پرسش‌ها و تأیید

| متغیر | خوانده‌شده توسط | اثر |
|---|---|---|
| `RT_ASSUME_NONINTERACTIVE` | نصب‌کننده، `config`، `row-template` | هر مقدار غیرخالی همهٔ پرسش‌ها را خاموش می‌کند، انگار ترمینالی وجود ندارد. در این حالت نصب‌کننده خوش‌آمدگویی و انتخابگر طرح را رد می‌کند، برندینگ را از متغیرهای بالا می‌گیرد و در صورت امکان پنل را خودکار فعال می‌کند. `row-template` بدون آرگومان به‌جای باز کردن منو، راهنما را چاپ می‌کند. |
| `RT_ASSUME_YES` | نصب‌کننده، `uninstall` | هر مقدار غیرخالی، دو کاری را تأیید می‌کند که در غیر این صورت به ترمینال نیاز دارند: **تعمیر** نصب موجود از داخل اسکریپت، و **حذف** بدون سؤال `[y/N]`. |

## منبع نسخه

به‌طور پیش‌فرض نسخه از `https://github.com/iitzSeriZdev/Row-Template/releases/latest/download` می‌آید. این متغیرها آن را برای نصب‌کننده، `row-template update` و بررسی به‌روزرسانی در منوی مدیریت تغییر می‌دهند:

| متغیر | اثر |
|---|---|
| `RT_RELEASE_DIR` | پوشه‌ای محلی که `manifest.txt`، `SHA256SUMS` و tarball را دارد. بر `RT_RELEASE_URL` مقدم است. [نصب دستی](/docs/installation/manual/) را ببینید. |
| `RT_RELEASE_URL` | نشانی پایهٔ HTTPS که همان فایل‌ها را ارائه می‌کند — آینهٔ خودتان. |
| `RT_ALLOW_INSECURE_URL` | اجازه می‌دهد `RT_RELEASE_URL` با یک هشدار، `http://` باشد. فقط برای آزمایش محلی؛ هرگز روی منبع پیش‌فرض HTTPS اثری ندارد. |

منبع هر چه باشد، بررسی SHA-256 همیشه انجام می‌شود. هیچ متغیری برای خاموش کردن آن وجود ندارد.

## پنل و ترمینال

| متغیر | اثر |
|---|---|
| `XUI_DB_FOLDER` | پوشه‌ای که `x-ui.db` پنل در آن است، وقتی در مسیر پیش‌فرض نیست. اگر فایل پایگاه‌داده‌ای آنجا باشد، فقط همان در نظر گرفته می‌شود — هرگز به نفع فایل دیگری کنار گذاشته نمی‌شود. |
| `NO_COLOR` | هر مقدار غیرخالی، خروجی رنگی را خاموش می‌کند. وقتی خروجی ترمینال نباشد هم رنگی در کار نیست. |

## یک نصب کامل بدون پرسش

```bash
RT_ASSUME_NONINTERACTIVE=1 \
RT_TEMPLATE=signature \
RT_SERVICE_NAME="Aurora VPN" \
RT_SUPPORT_URL="mailto:support@example.com" \
RT_LOGO_PATH=/root/logo.webp \
bash <(curl -fsSL https://github.com/iitzSeriZdev/Row-Template/releases/latest/download/install.sh)
```

کد خروج در صورت موفقیت `0` و در هر شکستی غیرصفر است؛ پس ابزارهای خودکارسازی می‌توانند آن را بررسی کنند. پس از آن `row-template verify` را اجرا کنید که فقط وقتی یک بررسی جدی رد شود کد غیرصفر برمی‌گرداند.
