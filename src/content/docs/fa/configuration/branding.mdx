Row-Template **به‌طور پیش‌فرض بدون برند** است: هیچ چیزی در صفحه نام Row-Template را نشان نمی‌دهد. می‌توانید سه چیز از خودتان اضافه کنید که همه اختیاری‌اند.

| فیلد | قواعد | کجا نمایش داده می‌شود |
|---|---|---|
| **نام سرویس** | حداکثر ۱۲۰ نویسه. بدون نویسهٔ کنترلی (مثل شکست خط). | همان جایی که طرح برندش را نشان می‌دهد. برای صفحهٔ بدون برند خالی بگذارید. |
| **لینک پشتیبانی** | باید با `https://`، `http://`، `tg://` یا `mailto:` شروع شود. | به‌عنوان دکمه یا پیوند پشتیبانی و تماس در صفحه. |
| **لوگو** | PNG، JPEG یا WebP، حداکثر **۲۵۶ کیلوبایت**، که از روی **محتوای** فایل شناسایی می‌شود، نه پسوندش. symlink پذیرفته نمی‌شود. | به‌جای مونوگرامی که خودکار ساخته می‌شود. |

بدون لوگو، صفحه یک **مونوگرام** از روی نام سرویس نشان می‌دهد — مثلاً `Katze-VPN` به `K-V` تبدیل می‌شود. نصب‌کننده برای نام‌های لاتین آن را پیش‌نمایش می‌دهد؛ برای خط‌های دیگر، مرورگر آن را محاسبه می‌کند.

## تغییر برندینگ

### از منوی مدیریت (یک فیلد در هر بار)

```bash
row-template
```

گزینهٔ **2 — Reconfigure branding** را انتخاب کنید:

```text
  1  Service name
  2  Support URL
  3  Logo
  4  Template
  5  Reset branding
  6  Reconfigure everything
  0  Back
```

- **Service name** — نام جدید را وارد کنید، برای نگه داشتن نام فعلی Enter بزنید، یا برای پاک کردن `-` وارد کنید.
- **Support URL** — نگه داشتن، تغییر یا حذف لینک. لینک نامعتبر رد و دوباره پرسیده می‌شود.
- **Logo** — استفاده یا جایگزینی تصویر، حذف آن (بازگشت به مونوگرام) یا نمایش وضعیت فعلی.
- **Reset branding** — هر سه را پاک می‌کند و به ظاهر پیش‌فرض برمی‌گرداند. Row-Template را حذف نمی‌کند.
- **Reconfigure everything** — همان `row-template config`.

### با فرمان config (همهٔ فیلدها)

```bash
row-template config
```

سه فیلد را به ترتیب و با نمایش مقدار فعلی می‌پرسد. برای نگه داشتن مقدار Enter بزنید، یا برای پاک کردن آن `-` وارد کنید.

### از داخل اسکریپت

مقادیر را به‌صورت متغیر بدهید. فیلدهایی که تنظیم نکنید مقدار فعلی‌شان را حفظ می‌کنند:

```bash
RT_ASSUME_NONINTERACTIVE=1 \
RT_SERVICE_NAME="Aurora VPN" \
RT_SUPPORT_URL="tg://resolve?domain=aurora_support" \
RT_LOGO_PATH=/root/aurora.png \
row-template config
```

برای پاک کردن نام از `RT_SERVICE_NAME=""` و برای حذف لوگو از `RT_LOGO_REMOVE=1` استفاده کنید.

## امتحان هر تغییری بی‌خطر است

تغییر برندینگ هرگز صفحهٔ سالم را با صفحهٔ خراب جایگزین نمی‌کند:

1. پیکربندی و صفحهٔ فعلی کنار گذاشته می‌شوند.
2. پیکربندی جدید نوشته می‌شود و صفحه از روی آن دوباره ساخته و اعتبارسنجی می‌شود.
3. فقط صفحه‌ای که از اعتبارسنجی عبور کند جایگزین می‌شود. اگر چیزی شکست بخورد، پیکربندی و صفحهٔ قبلی بازگردانده می‌شوند و خطا نمایش داده می‌شود.

## برندینگ چطور ذخیره می‌شود

مقادیر شما در `/etc/3x-ui/sub_templates/row-template/config.env` نگه داشته می‌شوند که فقط root و گروه آن می‌توانند بخوانند (مجوز `640`):

<File name="config.env">

```ini
# Row-Template configuration — generated file. Do NOT source this.
# Values are base64 data, read with grep+base64 and never executed.
RT_CONFIG_VERSION=1
TEMPLATE=row
SERVICE_NAME_B64=QXVyb3JhIFZQTg==
SUPPORT_URL_B64=aHR0cHM6Ly90Lm1lL2F1cm9yYQ==
LOGO_MIME=image/png
LOGO_DATA_B64=iVBORw0KGgo…
```

</File>

- متن‌ها **با کدگذاری base64** ذخیره می‌شوند و فقط به‌عنوان داده خوانده می‌شوند. این فایل هرگز source یا اجرا نمی‌شود.
- در صفحه، مقادیر به رشتهٔ دادهٔ سادهٔ جاوااسکریپت در یک بلوک ثابت تبدیل می‌شوند و طوری escape می‌شوند که هرگز نتوانند اسکریپت را ببندند یا نشانه‌گذاری اضافه کنند. سپس صفحه آن‌ها را به‌صورت **متن** قرار می‌دهد، هرگز به‌صورت HTML.
- لوگو به‌صورت data URI داخل صفحه جاسازی می‌شود، پس بدون درخواست اضافه بارگذاری می‌شود.

<Callout type="warning" title="config.env را دستی ویرایش نکنید">
  از منوی مدیریت یا `row-template config` استفاده کنید. مقداری که دستی ویرایش شده و نویسهٔ کنترلی دارد باعث می‌شود ساخت صفحه تا زمان اصلاح آن رد شود (`branding contains control characters; refusing to generate.`).
</Callout>

## برندینگ در برابر همه چیز ماندگار است

به‌روزرسانی، بازگردانی، تعویض تمپلیت و تعمیر، همه برندینگ شما را حفظ می‌کنند. بازگردانی، **نسخهٔ** قدیمی‌تری از صفحه را برمی‌گرداند، اما همیشه با برندینگ **فعلی** شما.
