title: شروع سریع

---

این صفحه مسیر کوتاه است. هر مرحله به توضیح کامل پیوند دارد، اگر خواستید.

<Steps>

### روی سرور پنل root شوید

وارد سروری شوید که پنل شما روی آن است و یک پوستهٔ root باز کنید:

```bash
sudo -i
```

<Callout type="warning">
  از یک پوستهٔ واقعی root استفاده کنید. `sudo bash <(curl …)` کار نمی‌کند: `sudo` توصیف‌گر فایلی را که `<(…)` می‌سازد می‌بندد، پس bash نمی‌تواند اسکریپت را بخواند.
</Callout>

بررسی کنید پنل شما از پنل‌هایی است که Row-Template پشتیبانی می‌کند:

<Tabs labels={["3X-UI", "PasarGuard", "Rebecca"]} sync="panel">
<Tab>

نسخه باید **3.6.0 یا جدیدتر** باشد:

```bash
/usr/local/x-ui/x-ui -v
```

</Tab>
<Tab>

PasarGuard نسخهٔ **5.x**، نصب‌شده با نصب‌کنندهٔ رسمی‌اش (Docker) یا از سورس (`pasarguard.service`). نصب‌کنندهٔ رسمی فرمان `pasarguard` را اضافه می‌کند:

```bash
pasarguard status              # the official (Docker) install
systemctl status pasarguard    # a source install
```

</Tab>
<Tab>

Rebecca نسخهٔ **1.x**، یعنی نسخهٔ Go — نصب باینری Rebecca که به‌صورت `rebecca.service` اجرا می‌شود. ایمیج Docker مربوط به Rebecca هنوز 0.0.x است و رد می‌شود؛ Rebecca نسخهٔ 1.x را با نصب‌کنندهٔ باینری‌اش (`rebecca-binary.sh`) نصب کنید.

```bash
systemctl status rebecca
```

</Tab>
</Tabs>

برای همهٔ چیزهایی که نصب‌کننده لازم دارد، [پیش‌نیازها](/docs/requirements/) را ببینید.

### نصب‌کننده را اجرا کنید

```bash
bash <(curl -fsSL https://github.com/iitzSeriZdev/Row-Template/releases/latest/download/install.sh)
```

نصب‌کننده دانلود را بررسی می‌کند، پنل شما را پیدا می‌کند و بعد چند سؤال می‌پرسد:

- **کدام پنل؟** — فقط روی سروری که بیش از یک پنل پشتیبانی‌شده دارد.
- **Continue installation?** — Enter بزنید.
- **Choose your Row-Template design** — یک شماره وارد کنید، یا برای Row کلید Enter را بزنید. می‌توانید اول [همهٔ طرح‌ها را ببینید](/docs/templates/).
- **Service name، Support URL، Logo** — همه اختیاری‌اند. برای رد شدن از هر کدام Enter بزنید.
- **Install with these settings?** — Enter بزنید.
- **Make Row-Template the active subscription page now?** — Enter بزنید. اول نشان می‌دهد فعال‌سازی چه چیزی را در پنل شما تغییر می‌دهد.

در 3X-UI پرسش آخر فقط وقتی می‌آید که `sqlite3` نصب باشد و پایگاه‌دادهٔ پنل پیدا شود؛ در غیر این صورت یک فیلد را خودتان در پنل تنظیم می‌کنید. [نصب‌کننده، پرسش به پرسش ←](/docs/installation/installer/)

### فعال‌سازی و بررسی

اگر نصب‌کننده Row-Template را برایتان فعال کرده، مستقیم سراغ `verify` بروید. در غیر این صورت:

<Tabs labels={["3X-UI", "PasarGuard", "Rebecca"]} sync="panel">
<Tab>

در پنل **Panel Settings → Subscription** را باز کنید، **Sub Theme Directory** را دقیقاً روی این مسیر بگذارید و ذخیره کنید:

```text
/etc/3x-ui/sub_templates/row-template
```

</Tab>
<Tab>

فعال‌سازی خودکار است. اگر از آن گذشتید، `row-template` را اجرا کنید و **5 — Activate / Re-apply theme** را انتخاب کنید.

</Tab>
<Tab>

با پایگاه‌دادهٔ پیش‌فرض SQLite و نصب بودن `sqlite3`، خودکار است. با MySQL/MariaDB در داشبورد Rebecca **Settings → Subscription → Templates** را باز کنید و این مقادیر را بگذارید:

```text
Subscription page template:   row-template/index.html
Custom templates directory:   /var/lib/rebecca/templates
```

</Tab>
</Tabs>

سپس کل نصب را بررسی کنید:

```bash
row-template verify
```

لینک اشتراک یکی از کلاینت‌ها را در مرورگر باز کنید. باید به‌جای صفحهٔ داخلی پنل، صفحهٔ Row-Template را ببینید. [دربارهٔ فعال‌سازی ←](/docs/installation/activation/)

</Steps>
