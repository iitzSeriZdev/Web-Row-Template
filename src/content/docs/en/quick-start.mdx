---
title: Quick Start
description: Install Row-Template on a 3X-UI, PasarGuard or Rebecca server, make it the active subscription page, and confirm it works — in three steps.
---

This page is the short path. Every step links to the full explanation if you want it.

<Steps>

### Become root on the panel's server

Log in to the server that runs your panel and open a root shell:

```bash
sudo -i
```

<Callout type="warning">
  Use a real root shell. `sudo bash <(curl …)` does not work: `sudo` closes the file descriptor that `<(…)` creates, so bash cannot read the script.
</Callout>

Check your panel is one Row-Template supports:

<Tabs labels={["3X-UI", "PasarGuard", "Rebecca"]} sync="panel">
<Tab>

The version must be **3.6.0 or newer**:

```bash
/usr/local/x-ui/x-ui -v
```

</Tab>
<Tab>

PasarGuard **5.x**, installed with its official installer (Docker) or from source (`pasarguard.service`). The official installer adds the `pasarguard` command:

```bash
pasarguard status              # the official (Docker) install
systemctl status pasarguard    # a source install
```

</Tab>
<Tab>

Rebecca **1.x**, the Go edition — Rebecca's binary install, which runs as `rebecca.service`. Rebecca's Docker image is still 0.0.x and is refused; install Rebecca 1.x with its binary installer (`rebecca-binary.sh`).

```bash
systemctl status rebecca
```

</Tab>
</Tabs>

See [Requirements](/docs/requirements/) for everything the installer needs.

### Run the installer

```bash
bash <(curl -fsSL https://github.com/iitzSeriZdev/Row-Template/releases/latest/download/install.sh)
```

The installer verifies the download, finds your panel, then asks you a few questions:

- **Which panel?** — only on a server with more than one supported panel.
- **Continue installation?** — press Enter.
- **Choose your Row-Template design** — type a number, or press Enter for Row. You can [preview every design](/docs/templates/) first.
- **Service name, support URL, logo** — all optional. Press Enter to skip any of them.
- **Install with these settings?** — press Enter.
- **Make Row-Template the active subscription page now?** — press Enter. It first shows what activation will change on your panel.

On 3X-UI the last question only appears when `sqlite3` is installed and the panel's database was found; otherwise you set one field in the panel yourself. [The installer, prompt by prompt →](/docs/installation/installer/)

### Activate and verify

If the installer activated Row-Template for you, skip to `verify`. Otherwise:

<Tabs labels={["3X-UI", "PasarGuard", "Rebecca"]} sync="panel">
<Tab>

In the panel open **Panel Settings → Subscription**, set **Sub Theme Directory** to exactly this path, and save:

```text
/etc/3x-ui/sub_templates/row-template
```

</Tab>
<Tab>

Activation is automatic. If you skipped it, run `row-template` and choose **5 — Activate / Re-apply theme**.

</Tab>
<Tab>

Automatic with Rebecca's default SQLite database and `sqlite3` installed. With MySQL/MariaDB, open **Settings → Subscription → Templates** in the Rebecca dashboard and set:

```text
Subscription page template:   row-template/index.html
Custom templates directory:   /var/lib/rebecca/templates
```

</Tab>
</Tabs>

Then check the whole installation:

```bash
row-template verify
```

Open any client's subscription link in a browser. You should see the Row-Template page instead of the panel's built-in one. [More on activation →](/docs/installation/activation/)

</Steps>
