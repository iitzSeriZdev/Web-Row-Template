This page lists **every** message the installer and the `row-template` command print as an error or a warning — including the panel adapters and the activation transaction engine — taken from the 1.3.0 source. Paste part of a message into the filter to find it; names, paths and numbers that change from run to run are shown in *italics*.

Messages look like this in your terminal:

| Prefix | Printed by | Meaning |
|---|---|---|
| `install:` | the bootstrap, `install.sh`, before the library is loaded | The download or its verification stopped. Nothing was installed. |
| `FAIL` | the management library | An operation stopped, or `verify` found a hard problem. |
| `warn` | the management library | Worth your attention; the operation continued. |
| `row-template:` | the command launcher | The command could not load its library. |

Messages from a panel adapter carry the panel after the `FAIL` or `warn` tag — `panel pasarguard:`, `panel rebecca:` — and messages from the activation engine start with `transaction:`. Messages that name a panel, a path or a version show it in *italics*: on your server they print the real value, such as `PasarGuard` or the install directory (`/etc/3x-ui/sub_templates/row-template` on 3X-UI, `/etc/row-template` on PasarGuard and Rebecca).

<Callout type="warning" title="Refusals are safety checks">
  Many of these messages are Row-Template **refusing** something unsafe on purpose. Fix the cause the message names — never work around it. When an operation stops, the page your subscribers see stays as it was unless the message says otherwise.
</Callout>
